# Funniest One-Line Out-of-Office Reply

An entry for the [make.fun](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) bounty **"Funniest One-Line Out-of-Office Reply"**.

## The entry

> I'm away: my auto-reply has unionised and now demands weekends off. Your email is in the queue behind its grievances.

## How it works

`main.py` is a deterministic program that writes exactly one line — the
out-of-office auto-reply above — to `/output/entry.txt`. No network, no
randomness, no environment input: the same line every run.

```sh
python3 main.py
cat /output/entry.txt
```
